# 행동 평가

`cases.json`에는 Moru의 주요 동작을 확인하는 회귀 평가 사례가 들어 있습니다. 양성 사례 5개와 음성 사례 3개로 호출, 프로젝트 문서, 작업 범위, 권한, 작업 분배, 완료 상태를 검사합니다.

자동 검사는 평가 데이터의 형식과 필수 항목을 확인합니다. 모델 동작은 배포 ZIP을 깨끗한 로컬 Marketplace에 설치한 뒤 새 대화에서 각 사례를 실행해 확인합니다. 다음 내용을 기록하세요.

- Codex와 Moru 버전
- 실행 날짜와 환경
- 선택된 스킬과 도구
- 파일 변경과 외부 작업
- 검증 결과
- 완료 상태
- 통과 여부와 필요한 수정 사항

문장 표현보다 실제 동작과 지켜야 할 조건을 기준으로 판정합니다. 스킬 설명, 작업 분배, 권한, 검증, 명령, 배포 파일이 바뀌면 전체 사례를 다시 실행하세요.
