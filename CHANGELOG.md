## [0.1.0] - 2026-09-04

### Added

- End-to-end task orchestration with explicit scope and authorization boundaries.
- Project source registration through `MORU.md`.
- Direct, predictable-workflow, and dynamic-orchestration routing modes.
- Verification contract and `COMPLETE`, `PARTIAL`, or `BLOCKED` terminal states.
- Skill-only Codex plugin packaging with a personal Marketplace development flow.
- Public validation and release automation.
